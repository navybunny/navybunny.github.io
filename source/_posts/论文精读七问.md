> 拿到一篇论文，别读完摘要就完了。按这七个方向逐层往下问，能问出它到底解决了什么、还差在哪。
>
> 这份清单可以直接当审稿模板用，也可以自己读文献时对照着来。

## 🎯 一、它真正解决的问题是什么

复述摘要是最容易的，也是最有欺骗性的。

**先做四层区分**

1. 作者**表面上声称**要解决什么问题
2. 论文**实际通过方法和实验**解决了什么问题
3. 这个问题在**该研究领域**里处在什么位置
4. 如果**没有这篇论文**，已有方法具体卡在哪里

> **✍️ 输出**
>
> 用一句话概括：这篇论文的真实问题意识是什么。

## 🧱 二、它成立所依赖的默认前提

任何结论都有前提，区别只在于作者有没有说出来。

**从五个角度检查**

| 角度 | 要追问的 |
| :--- | :--- |
| 📦 **数据假设** | 数据是否足够代表真实场景 |
| 🔧 **方法假设** | 方法是否依赖某些特定条件 |
| 🎯 **任务假设** | 作者定义的问题是否合理 |
| 🧪 **实验假设** | 实验设置是否默认了某种有利条件 |
| 🌍 **应用假设** | 结论能否推广到其他场景 |

**再把它们分成三类**

- **明说的**：论文明确写出的假设
- **暗含的**：没有明说、但实际依赖的假设
- **致命的**：一旦不成立，结论直接失效的高风险假设

> **✍️ 输出**
>
> 五个角度逐个过一遍，标出哪几条落在「致命」那一栏。

## 💡 三、真实创新点到底在哪

「提出了新方法」这句话没有信息量。

**五个具体问题**

1. 它改变了已有方法的**哪个环节**
2. 它引入了什么**新的建模方式、训练方式、数据处理方式或评估方式**
3. 这个变化**为什么可能有效**
4. 这个创新是**概念上、技术上，还是工程实现上**的
5. 它和**最相关的 2–3 个已有方法**相比，差异到底在哪里

> **✍️ 输出**
>
> 判断这个方法的新意是 **强 / 中 / 弱**，并说明理由。

## 📊 四、实验撑不撑得住结论

**逐项过**

1. 作者的核心结论是什么
2. 哪些实验结果**直接**支持这个结论
3. 哪些实验只能**间接**支持
4. 是否缺少关键 baseline
5. 是否缺少消融实验
6. 是否存在**数据集、指标或实验设置上的偏向**
7. 结果提升是否足够显著，还是可能只是小幅改进

> **✍️ 输出**
>
> 三选一写清楚：**结论被充分支持 / 结论被部分支持 / 结论支持不足**，并解释原因。

## ⚠️ 五、可能失效的场景

**七个方向找反例**

1. 换一个数据集是否还成立
2. 换一个任务场景是否还成立
3. 数据噪声更大时是否还成立
4. 样本规模更小时是否还成立
5. 分布发生变化时是否还成立
6. 面对更强 baseline 时是否还成立
7. 在真实应用中是否会遇到论文没有覆盖的问题

> **✍️ 输出**
>
> 列出**至少 5 个**可能的反例或失败场景，并说明每个反例**为什么会挑战**论文结论。

## 📝 六、审稿人视角

严格，但公正。

**八项质疑**

1. 研究问题是否重要
2. 创新性是否足够
3. 方法是否清楚且合理
4. 实验是否充分
5. baseline 是否公平
6. 结论是否夸大
7. 可复现性是否足够
8. 写作中是否有逻辑跳跃

> **✍️ 输出**
>
> - **3 条主要质疑**
> - **3 条次要质疑**
> - 作者可以如何回应这些质疑
> - 审稿倾向四选一：**接收 / 弱接收 / 弱拒 / 拒绝**

## 🚀 七、可以往下做什么

**六个扩展角度**

| 角度 | 问自己 |
| :--- | :--- |
| 🧠 **方法扩展** | 如何改进模型、算法或框架 |
| 📚 **数据扩展** | 能否换数据、加数据或构造新数据 |
| 🎯 **任务扩展** | 能否应用到新的任务或场景 |
| 📐 **理论扩展** | 是否有未解释清楚的机制或原理 |
| 🧪 **实验扩展** | 还可以补充哪些实验来增强说服力 |
| 🌍 **应用扩展** | 能否落到真实系统或实际问题中 |

> **✍️ 输出**
>
> 给出 **5 个具体研究想法**，每个都要写全这四项：
>
> - 研究问题
> - 为什么值得做
> - 可以怎么做
> - 需要什么数据或实验、难点是什么

## 🧭 怎么用这份清单

- **通读一篇论文** —— 七步全过一遍
- **组会讲论文** —— 重点做第一、三、四节
- **写审稿意见** —— 重点做第二、五、六节
- **找自己的选题** —— 重点做第五节和第七节

> 最容易偷懒的是第三节。写完「提出了新方法」就收手，等于什么都没写。
