## 内容分区

- **摄影** —— 尼康 D4 数码作品集、胶片日记（柯达金 200 / 巨星 400 / 一次性半格机）
- **随笔** —— 一些诗与记录
- **编程** —— 计算机学习笔记（C++ 等）

## 关于这个仓库

这个仓库用两个分支分工：

| 分支 | 存放内容 |
|---|---|
| **`main`**（你正在看的） | 博客的**发布产物**：Hexo 生成的 HTML / CSS / JS，GitHub Pages 从这里发布 |
| **[`source`](https://github.com/navybunny/navybunny.github.io/tree/source)** | **源码**：Markdown 原文、图片、主题、配置文件 |

想改内容请看 `source` 分支，`main` 里的文件是自动生成的，手改会被覆盖。

## 技术栈

- [Hexo](https://hexo.io/) 8 —— 静态博客生成器
- 自建主题 `miku-theme` —— 初音未来配色 + 视差首页
- 图片全部压到长边 2560px / JPEG q88（原图 570 MB → 54 MB）
- 部署到 GitHub Pages
